# 數位邏輯自學 · 三欄（DAT）

離線 HTML 自學：左課程目錄｜中教學＋練習｜右「定義 · 範例 · 引導提示」（逐步解鎖）。

## 開啟方式

- 建議：喺本資料夾執行 `python3 -m http.server 8765`，瀏覽器開 `http://localhost:8765/`
- 或者直接用瀏覽器開 `index.html`（已內嵌 `lessons-data.js`，一般可離線用）

## UX（對齊電學自學）

- 中欄工具列：**上一題｜提示｜檢查｜重試｜下一題**
- 撳「提示」逐步解鎖右欄「引導提示」（未解鎖顯示灰卡）
- 答錯可自動解鎖第 1 則引導；提示係引導問題，唔直接講答案
- 頂欄可摺疊左目錄／右支援

## 練習類型

- **mcq** 選擇題
- **truth** 真值表填 0／1
- **kmap** 卡諾圖填格＋讀簡式（2×2、2×4、4×4）
- **design** 成果9：選閘 → 布林式 → 真值表
- **tt-live** 真值表／K-map ↔ 布林公式（雙向即時；補式用 CSS `.obar`）

## 檔案

- `index.html` — 三欄殼
- `app.js` — 互動（含 hintStep）
- `lessons.json` / `lessons-data.js` — 課文與練習
- `assets/` — 閘符號、校本定律表／示意圖（無教科書／掃描圖；僅校本示意）

進度存於瀏覽器 `localStorage`（鍵：`dat-logic-3col-progress-v1`）。
